# Smart Study Planner

## Introduction
Smart Study Planner is a simple web application designed to help students organize and manage their study tasks.

## Objective
The objective of this project is to help students create study tasks, set priorities and deadlines, and track their progress.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage

## Key Features
- Add study tasks
- Select subjects
- Set priority
- Set deadline
- Mark tasks as completed
- Delete tasks
- Track study progress
- Save tasks using Local Storage
- Responsive design

## Project Structure
index.html - Website structure
style.css - Website styling
script.js - Application functionality

## Conclusion
Smart Study Planner is a simple and useful application for managing study activities. This project demonstrates the practical use of HTML, CSS, and JavaScript.
